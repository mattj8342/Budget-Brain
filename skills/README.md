# Budget Brain skill sources

Five skills are implemented in the private deployment: Assign Paycheck, Review Budget, Record Transactions, Explore Impacts and Check Sustainability. Guided Settings is included as an instruction draft for the onboarding integration.

Each folder contains a SKILL.md entrypoint and supporting references. Financial policy comes from authenticated household settings and live YNAB data, not personal values embedded in reusable instructions.

Tool references describe supported capabilities and explicit limits. The shared runtime contract also describes broader intended behavior; it is not evidence that every capability exists. Discover actual tools and respect the implementation table in the root README.

These folders do not include a private App binding, OAuth client configuration or installable public plugin identity. Package/install the instruction assets through the intended client's supported workflow.
